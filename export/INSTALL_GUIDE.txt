HOW TO INSTALL ON YOUR ANDROID PHONE:
------------------------------------------------------------------------

METHOD 1: PHONE TRANSFER (RECOMMENDED)
1. Transfer "ActiDay.apk" to your phone via:
   - USB cable (copy into phone's "Downloads" folder)
   - WhatsApp / Telegram (send the file to yourself)
   - Google Drive / Email attachment / Bluetooth
2. On your phone, tap the APK file in Downloads or File Manager.
3. Select "Install".
   (Note: If prompted with "Install unknown apps", tap Settings and 
   enable "Allow from this source" for your file manager or browser).
4. Tap "Open" and start using ActiDay!

METHOD 2: VIA ADB / USB DEBUGGING (DEVELOPER MODE)
If your phone is connected with USB Debugging enabled, run:
   "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r "C:\Users\Mahab\Desktop\ActiDay.apk"
